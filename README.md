# Little Lemon – Restaurant Website

Capstone project for the Meta Front-End Developer Professional Certificate: a responsive website for the fictional Little Lemon restaurant, built with React.

## Features
- Home page with hero section, weekly specials and footer
- Mobile navigation menu
- Table reservation page with form validation:
  - required name, email and phone, with email and phone format checks
  - at least 1 guest
  - date and time picker
  - error message shown under each invalid field

## Tech
React 18 · React Router · react-hook-form · Yup · styled-components · Framer Motion

## Run locally
    npm install
    npm start

Then open http://localhost:3000.
